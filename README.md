## 📖 About

Yajurveda Scholar is a web-based platform designed for Vedic scholars, spiritual seekers, and anyone interested in exploring the ancient wisdom of the Yajurveda. The application provides access to:

- **Shukla (White) Yajurveda** - Vajasaneyi Samhita (Madhyandina recension)
- **Krishna (Black) Yajurveda** - Taittiriya Samhita
- **Satapatha Brahmana** - One of the most important Brahmana texts

## ✨ Features

- 📚 **Explore** - Browse verses with Sanskrit text and English translations
- 🔍 **Search** - Find specific verses, mantras, or concepts
- 📊 **Analysis** - Text analysis, comparisons, and visualizations
- 🤖 **AI Scholar** - Ask questions about Vedic literature (powered by Groq)
- 🔊 **Audio** - Listen to Vedic recitations
- 📝 **Study Tools** - Bookmarks, notes, and glossary

## 🛠️ Technologies

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Recharts (visualizations)
- Groq AI (optional, for AI Scholar feature)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or bun

### Installation

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd yajurveda-scholar

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Environment Variables (Optional)

For AI-powered features, create a `.env` file:

```env
VITE_GROQ_API_KEY=your_groq_api_key
VITE_TAVILY_API_KEY=your_tavily_api_key  # For web search
```
